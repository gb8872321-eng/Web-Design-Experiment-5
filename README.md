# Web Design Experiment 5

Weather app using the Fetch API. It takes a city name from the user and shows the real-time temperature, humidity and wind speed.

The Open-Meteo API is used. It is free and does not need an API key.

## Files
- index.html - structure of the app
- style.css - styling
- script.js - fetches data from the API and shows it on the page
